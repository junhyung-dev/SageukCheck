## 1. 워크플로우 v6

- export 정보: 에이전트 `agt_JfWkL5Ca5v5SUDYL2GwARR`, 워크플로우 이름 `미션2_사극체크`, `configVer: 6`, 2026-11-09T15:52Z(11/10 00:52 KST) export
- `.env`의 `UPSTAGE_CONFIG_ID=6`과 같다. v6 이후 새 config가 있는지는 Studio 화면에서만 확인할 수 있다.

```
PDF → Parse(OCR force) → Classify 사극문서_분류 (split: CONTINUITY)
   script              → 대본_주장추출
   source_record       → 사료_본문추출       (실록 원문 · 국역 등 기록 본문)
   source_digest       → 사료_인용해설분리   (해설 · 연표 · 요약 등 정리 자료)
   source_form_unknown → 사료_판독확인       (흐리거나 잘려 형식을 가를 수 없는 사료)
   review_request      → 요청_범위추출
   very_others         → (연결된 노드 없음)
→ Merge 고증자료_병합 → Instruct 역사고증_판정 (enum: 일치 / 충돌 / 검토 필요)
```

### 추출 항목
| 스키마 | 주요 항목 |

| 대본_주장추출 | `scene_id`, `script_period`, `script_read_status`, `script_claim_lines`, `claim_rows[]`(장면 ID, 대본 인용, 유형, 행위자, 행위, 대상 · 수량, 사건 시점, 지정 여부) |

### 판정 프롬프트 (요약)
1. 첨부 및 대조 가능 여부 확인: 필수 문서는 대본과 사료, 요청서는 선택
2. 대본의 검증 대상 선택: 요청서 범위 → 대본이 지정한 후보 → 유일한 후보 순
3. 같은 사건인지 확인 후 시점 · 인물 · 행위 · 발언 · 수량을 요소별로 대조. 기사 기록일과 사건 발생일, 명령과 실행, 창제 · 완성 · 반포를 구분
4. 최종 판정: 전제 불성립이나 사료 간 충돌은 검토 필요 → 직접 모순은 충돌 → 모두 뒷받침되면 일치 → 그 밖은 검토 필요

출력 지시 중 정답과 직접 관련된 부분:
- `source_reference`: "확인된 사료 출처. 여러 출처는 각각 구분한다. 확인된 출처가 없으면 \"\"" (형식 지정 없음)
- `missing_documents`: 허용 값 `"사극 대본"`, `"역사 사료"`, 없으면 `[]`
